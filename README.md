# 동영상 줄이기

휴대폰 동영상을 카카오톡으로 보내기 좋은 크기(360p~1080p 선택, H.264 MP4)로 줄여 주는 간단한 웹앱. 영상은 서버로 보내지 않고 기기 안에서(WebCodecs) 처리합니다.

- 해상도 선택: 360p / 480p / 720p / 1080p (원본보다 큰 해상도는 숨김), 하드웨어 인코더 우선, 소리는 그대로 복사
- 30MB가 넘으면 같은 길이로 자동 분할 (Claude 업로드용, 끌 수 있음), 완성된 조각부터 바로 저장 가능
- 섯다 분석용 사진: 1·2·3초 간격 캡처, 변화 없는 장면 건너뛰기, 8장씩 묶은 JPG(시각 표시 포함)
- 압축: [Mediabunny](https://mediabunny.dev) 1.61.1 (MPL-2.0)
- 안드로이드: 앱 설치 후 카카오톡 등에서 공유 → 동영상 줄이기

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)
