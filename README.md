# 동영상 줄이기

휴대폰 동영상을 카카오톡으로 보내기 좋은 크기(480p·720p, H.264 MP4)로 줄여 주는 간단한 웹앱. 영상은 서버로 보내지 않고 기기 안에서(WebCodecs) 처리합니다.

- 두 가지 방식: 빠르게(480p) / 화질 좋게(720p), 하드웨어 인코더 우선, 소리는 그대로 복사
- 압축: [Mediabunny](https://mediabunny.dev) 1.61.1 (MPL-2.0)
- 안드로이드: 앱 설치 후 카카오톡 등에서 공유 → 동영상 줄이기

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)
